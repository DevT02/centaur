The Clipboard Centaur workflow

Your code stays local until you choose what to share.

Three entry points feed the same validation, review, write, and recovery pipeline.

MCP-connected client
get_context(mode: "changed")

The client can read only the workspace fixed during setup.

Browser chat
centaur --export --mode changed

You decide which generated context files to upload.

CLI or editor
centaur --file response.txt

Clipboard, file, and stdin inputs use the same patch planner.

One fail-closed safety core

workspace-scoped

4

Recover
