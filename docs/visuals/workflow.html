How an AI edit reaches your files

Your repository stays on your machine. Only the context you scope leaves it, and nothing is written until every block in the reply has been checked and you have approved the result.

centaur undo restores the snapshot taken before a write. It stops instead of overwriting a file you changed after Centaur touched it.

Three ways to drive the same loop

get_context(mode: "changed")

An MCP client reads context directly, limited to the workspace you fixed at setup.

centaur --export --mode changed

Writes context files to disk. You choose which of them to upload to a chat.

centaur --file response.txt

Takes the reply back from a file, the clipboard, or stdin, through the same checks.
